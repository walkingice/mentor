# Introduction

- 協助教師做計算學生分數的網頁：教師手動輸入，或是貼上學生分數之後，即時並自動地算出各種資訊，且支援匯出檔案。

# Spec

- 畫面分成兩部分
    - 右側是計算完的結果
    - 左側是輸入的部分，有兩欄的表格
        - 第一欄是座號，第二欄是成績。
        - 預設就有 100 列，代表最多可輸入 100 位學生
- 畫面下方會有個常駐無視捲動的訊息欄，無訊息時為看不見

- 每次輸入的數字有更動，即時自動更新計算結果
- 計算結果包括
    - 總平均
    - 標準差
    - 中位數
    - 級距
        - 100 分以上
        - 99～90
        - 89～80
        - 79～70
        - 69～60
        - 60 以下
    - 以分數排序的座號列表，要顯示分數與座號
- 輸入欄位
    - title 的後方有個小按鈕「清除全部」
    - 第一 row 就是座號 1 號，第二 row 就是座號 2 號，以此類推
    - 可能會有某個座號無學生，空白字元或是換行代表無學生
    - 學生可能考零分，因此輸入 0 代表有學生
    - 負分數無法計算，只要有低於零的分數，該輸入數字用紅色標註，並且顯示警告訊息
- 輸入方式調整：為了易於教師使用，有些調整游標的方式
    - 可以用複製貼上的方式，遇到換行就移動到下一 row
    - 按下 Enter 就到下一個 row，空的輸入欄又按下刪除會到上一個 row
    - 游標上下鍵可以切換 row
    - 輸入框取得 focus 時，如果裡面已經有數字，自動 select 輸入框內的所有字
    - 輸入的數字為 100～20 之間時，自動切換到下一個 row
- 輸出
    - 有個「輸出計算結果」的按鈕，按下後可以輸出 markdown 格式的 txt 檔，檔名為當下的 timestamp，包括「年月日_時分秒」
    - 輸出學生成績時，由於預設輸入欄位有 100 rows，只輸出到最後一位有成績者。中間無成績用「--」表示
    - 格式如下
    ```markdown
    # 班級成績表

    ## 計算結果

    .....

    ## 學生成績

    01. 90
    02. 89
    03. 95
    04. --
    05. 79
    06.  0
    07. 64
    ....

    ```
