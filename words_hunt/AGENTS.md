# Introduction

- 製作尋找文字小遊戲的題目工具。教師提供數組文字，程式將其放入方格，讓學生尋找。
- 未使用的方格會填入其他文字，用來隱藏答案。

# Spec

- 頁面頂端有列數與欄數兩個數字選擇框，各自預設為 7，範圍為 7 到 20；允許 7 × 10 等長方形。
- 接著是多行題目輸入框，一行代表一組題目。
- 接著是填充文字輸入框，再來是「生成」按鈕與 output。
- 正規化題目與填充文字時，移除標點、符號、空格、Tab、其他空白字元及 emoji；將半形英文字母與數字轉為全形。保留其他文字與數字。
- 題目以行為單位正規化，移除正規化後的空白行，再移除重複題目，保留第一筆。
- 填充文字正規化後，移除所有出現在題目中的字。若結果為空，填格時使用「。」作為預設字；此預設字不再經過正規化。
- 生成前驗證題目：至少要有一組；每組必須能在列或欄的長度內排放。無法完成排放時顯示錯誤，不顯示不完整的 output。
- 亂數將每組題目排成連續直線；允許水平、垂直與斜向，可正序或倒序。
- 不同題目可交疊，但只有相同的字可以共用同一格；不可覆蓋不同的字。排放遇到衝突時重新嘗試配置，超過嘗試上限時顯示錯誤。
- 題目排放完成後，從可用的填充字中亂數選字，填滿剩餘方格。
- output 包含題目清單及置中的方格表格；表格為指定列數 × 欄數，每格大小相同。
- 列印時以 `@media print` 隱藏其他內容，只列印 output，縮放至 A4 單頁。
- 使用 `localStorage` 保存使用者輸入：列數、欄數、原始題目文字及原始填充文字；不保存生成的 output。所有 key 使用 `mentor_words_hunt` 前綴，並定義 `STORAGE_PREFIX_KEY=mentor_words_hunt`。

# Implementation

- 此功能位於單一 HTML 檔；遵循上層 `AGENTS.md` 的專案規則。
- 使用上層 `test_lib.js` 撰寫功能單元測試，不需第三方函式庫。
- 英文實作步驟與驗收項目見 `PLANS.md`。
