# Introduction

- 製作尋找文字小遊戲的題目的工具：教師提供幾句話，本程式會將其放入 N x N 的方格內，讓使用者尋找那些文字擺在哪裡
- 沒被用到的方格內還會填入其他文字，用來隱藏答案

# Spec

- 最上方有兩個數字的選擇框，可以決定是幾乘幾的的大小，預設值且最小為 7 x 7，最大為 20 x 20
- 接著是多行文字的輸入框，用來輸入題目。
    - 一行就是一組文字
    - 正規化：移除掉任何的符號，不分全形半形，包括 `，！「」。；『』{},!.、` 以及其他常見的符號。如果提供的是英文或數字，轉成全形文字當成題目使用。

- 接著是填充文字，用來填補空格。讀取填充文字的正規化跟題目文字相同，要移除掉符號，並且轉為全形。
- 如果填充文字是空的，預設值是「。」
- 然後是「生成」按鈕，按下去之後生出題目 (在本專案稱之為 output)
- 最後就是 output，output 是 N x N 的表格，置中，每一格大小相同。
- 當使用者要列印時，隱藏所有的內容，利用 `@media print { }`只留下 output，列印 A4 單頁的輸出。

產生 output 的邏輯如下

- 讀入題目文字與填充文字，做正規化
- 驗證：檢查題目文字的長度或總和是不是超過方格尺寸，若超過則顯示錯誤訊息
- 檢查填充文字是不是有出現在題目文字裡面，若有，則移出填充文字
- 排放題目文字
    - 亂數選擇位置，將題目文字放入。
    - 可以直放，橫放，或將題目文字倒序後再放置
    - 若題目文字裡面有重複的字，譬如說「你我他」「其他」，放置的時候相同的字可以共用同一格
- 題目文字擺放完之後，再從填充文字裡面亂數選擇，並填滿剩下的空格
